# Atlas Versus public website

Support and privacy pages for Atlas Versus on iPhone, iPad and Mac.

- Support: https://arthuryess.github.io/versus-site/
- Privacy: https://arthuryess.github.io/versus-site/privacy.html
- Support requests: https://github.com/arthuryess/versus-site/issues

## Publish

Commit the prepared files and push main using GitHub Desktop. In repository Settings → Pages, select Deploy from a branch, main and /(root), then Save. No custom domain or build dependencies are required. The pages become live after GitHub finishes its Pages deployment.

## Updates

Edit the HTML/CSS, review both themes on phone and desktop, then commit and push. Keep the effective date accurate when the policy changes, and keep app-store/site in the versus app repository consistent with these published pages. Do not store private app source, keys or user records here.
